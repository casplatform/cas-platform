Orbital Risk Assessment

Query a satellite or a candidate orbit. CAS returns its collective collision burden (OCBI), percentile ranking against the LEO population, and an exportable Risk Factor Sheet.

With an inclination, exposure is gated to planes that actually cross yours. Leave it blank to see the whole altitude shell.
The object’s current orbit is resolved from the public catalogue, then its shell is assessed.
Consumes 1 report credit

Watch the orbits you carry. CAS checks them weekly and notifies you only when something changes materially — a growing threat population, a climb in the LEO ranking, or a fragmentation event inside the band.

Authentication

Insurance endpoints authenticate with a JSON Web Token obtained from the login endpoint. Send it as a bearer token on every request. The account API key shown in Settings is for the operator engine and is not accepted here.

curl -X POST https://casplatform.com/api/auth/login \\
  -H "Content-Type: application/json" \\
  -d '{"email":"you@example.com","password":"..."}'

# response: {"status":"ok","token":"eyJ...","role":"insurer","tier":"insurer_pro"}

Example — OCBI across a peer set
curl -X POST https://casplatform.com/api/v2/insurance/ocbi \\
  -H "Authorization: Bearer $TOKEN" \\
  -H "Content-Type: application/json" \\
  -d '{"orbits":[
        {"label":"SSO 750","altitude_km":750,"inclination_deg":98.0},
        {"label":"SSO 800","altitude_km":800,"inclination_deg":98.6},
        {"label":"Starlink 550","altitude_km":550,"inclination_deg":53.0}
      ]}'

OCBI is a relative index: kappa and cascade are normalised across the orbits you submit, so at least three are required and a score is only meaningful against the others in the same request.
