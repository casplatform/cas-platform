2. Description of Service

CAS is a conjunction decision support platform for satellite operators. It is not a collision avoidance system: it does not execute maneuvers, it has no link to any spacecraft, and every output is advisory. The Service provides:

  • Real-time conjunction data monitoring via Space-Track CDM integration
  • Collision probability (Pc) computation using the Foster/Chan 2D Gaussian method
  • Maneuver option evaluation with cascade analysis, for the operator to act on or disregard
  • Operator satellite watchlist monitoring with automated alerting
  • REST API access for programmatic integration
  • Historical conjunction data analysis and Pc trend tracking

3. Important Disclaimer — Limitation of Liability

CAS is NOT an autonomous collision avoidance system: it does not execute, command or plan maneuvers, and it has no link to any spacecraft. CAS does NOT replace professional mission operations judgment. All maneuver decisions are the sole responsibility of the satellite operator.

3.1 No Guarantee of Accuracy

CAS states no accuracy figure for any collision probability it reports, here or anywhere else in the Service. What is validated is consistency, not accuracy: the numerical Pc implementation is verified against closed-form analytical references and against itself across inputs. That is a different claim from the computed value being the true probability of collision, which would require covariance data that public sources do not provide.

Collision probability calculations are inherently uncertain. Orbital propagation errors, atmospheric drag variations, solar activity, untracked debris and covariance matrix limitations affect every such computation, including ours.
